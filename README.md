# Movement-Detection
This project is designed to help a computer "see" when something moves in front of a camera. Instead of just recording everything, the program constantly looks for changes in the environment and flags only the moments when something actually happens.

How to Run the Project
Open your terminal or command prompt and navigate to the project folder.

Run the script using your compiler or interpreter (for example, python main.py or running the compiled .exe).

Wait for the window to appear. You should see the live video feed from your camera.

Test the detection: Move your hand or walk in front of the camera. The program will highlight the movement.

Controls
To keep things simple, there is only one main control:

Press the q key on your keyboard to stop the camera and close the program safely.

Note: Make sure the video window is "active" (clicked on) before you press q, or the computer might not realize you are trying to talk to the program.
